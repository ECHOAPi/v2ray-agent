# 端口流量监控

端口流量监控位于 `vasma → 19.端口流量监控`。该功能只按 Xray 入站端口统计，不再创建或保留用户级统计。

当前提供以下能力：

- 聚合同一端口对应的全部 Xray 入站标签，并统计上行与下行流量。
- 同时记录每日、自然月、自定义结算周期和累计流量。
- 可为每个端口分别设置四类额度；`0` 表示不限额。
- 达到可配置阈值时告警，超额后自动停用该端口。
- 每日、自然月或自定义周期重置后，如果没有其他超额原因，会自动恢复端口。
- 每分钟采集一次，每天生成上一日 CSV 报告；也可在 vasma 中查看当前用量或即时生成报告。
- 告警可写入本地日志，也可发送到 Telegram 或 HTTPS Webhook。

## 统计与停用方式

监控组件在 `127.0.0.1:10085` 启用 Xray `StatsService`，API 不对公网监听。组件启用 Xray 的入站上行、下行统计，并读取以下形式的绝对计数器：

```text
inbound>>>入站标签>>>traffic>>>uplink
inbound>>>入站标签>>>traffic>>>downlink
```

采集器根据 Xray 配置把入站标签映射到监听端口。同一端口有多个入站标签时，其流量会合并到一个端口记录。采集器保存每个核心计数器的上次读数并按差值入账，因此重复轮询不会重复计算；核心重启导致计数器归零时也会自动识别。

超额停用不会删除 Xray 入站、账号或订阅。组件会在现有路由规则首部维护一条 `inboundTag` 黑洞规则，使该端口对应的全部入站流量无法转发。周期重置后只移除组件自己管理的黑洞规则。每次写入核心配置前，都会使用 `xray run -test -confdir` 校验完整配置。

## 周期语义

| 周期 | 重置规则 |
|---|---|
| 每日 | 服务器本地时间每天 00:00 |
| 自然月 | 每月 1 日 00:00 |
| 自定义结算周期 | 每月所选结算日 00:00；结算日限制为 1–28 |
| 累计 | 永不自动清零 |

一个端口可以同时配置多类额度。任意额度超限都会触发停用。只有全部会重置的超额原因都消失，并且累计额度也没有超限时，端口才会自动恢复。

阈值告警与超额告警按“端口、周期、周期键、阶段”去重。例如每日额度在新的一天会使用新的周期键，因此可以再次触发告警。

## vasma 操作

进入 `vasma → 19.端口流量监控` 后可以：

1. 启用或停用监控。
2. 查看每个端口的今日、本月、自定义周期、累计用量和当前状态。
3. 选择端口并配置四类额度与自定义结算日。
4. 配置告警阈值、通知方式和超额自动停用。
5. 立即采集或生成 CSV 报告。

停用整个监控功能时，组件会移除定时任务、StatsService 配置和自己维护的黑洞规则，保留历史数据，并解除端口限制。

## 报告、日志与权限

数据位于 `/etc/v2ray-agent/traffic/`：

- `config.json`：端口额度、阈值和通知设置。
- `state.json`：端口累计状态、核心计数器基线和周期历史。
- `reports/`：以端口为第一列的 CSV 报告。
- `alerts.log`、`collect.log`：告警和采集日志。

目录权限为 `0700`，其中的配置、状态、报告和日志为 `0600`。Telegram Token 与 Webhook URL 不会输出到菜单或日志。Webhook 仅接受 HTTPS 地址。

配置格式版本为 `2`，键名为 `ports`。如果曾测试过早期用户级预览版本，启动新版时会移除旧的 `users` 配置与状态，因为用户额度无法无歧义地换算为端口额度；请在 vasma 中重新设置端口额度。

## sing-box 限制

sing-box 的精确入站统计依赖构建标签 `with_v2ray_api`。v2ray-agent 当前使用的官方发布包没有包含该标签，因此：

- 纯 sing-box 安装会拒绝启用端口流量监控。
- 同时运行 Xray 与 sing-box 时，必须明确确认“仅监控 Xray 端口”；sing-box 端口流量不会计入额度。

组件不会使用防火墙字节计数替代核心统计，以免把握手失败、反向代理或其他服务流量错误计入端口额度。

## 测试

在仓库根目录运行：

```bash
bash tests/traffic_monitor_test.sh
```

测试覆盖同端口多入站聚合、不同端口隔离、仅入站计数、绝对计数器去重与归零、四类周期、阈值告警去重、端口自动停用与恢复、现有路由保留、残留锁恢复和 CSV 报告。
