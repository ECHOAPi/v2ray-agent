# 用户流量监控

用户流量监控位于 `vasma → 用户管理 → 用户流量监控`，当前提供以下能力：

- 按逻辑用户聚合其所有 Xray 协议账号的上行与下行流量。
- 同时记录每日、自然月、自定义结算周期和累计流量。
- 可分别设置四类额度；`0` 表示不限额。
- 达到可配置阈值时告警，超额后自动停用；周期重置且无其他超额原因时自动恢复。
- 每分钟采集一次，每天生成上一日 CSV 报告；也可在菜单中即时生成报告。
- 告警可写入本地日志，也可发送到 Telegram 或 HTTPS Webhook。

## 统计与停用方式

监控组件在 `127.0.0.1:10085` 启用 Xray `StatsService`。API 不对公网监听。采集器保存每个核心计数器的上次读数，按差值入账；计数器因核心重启归零时会自动识别。

项目为同一用户创建的协议账号带有不同后缀，例如 `alice-VLESS_WS` 和 `alice-VMess_WS`。监控组件沿用项目现有规则，以第一个 `-` 前的内容作为逻辑用户名并聚合流量。因此自定义用户名不应包含 `-`。

超额停用不会删除账号或订阅。组件会在现有 Xray 路由首部维护一条用户级黑洞规则；恢复时只删除自己管理的规则。每次修改核心配置前，都会使用 `xray run -test` 校验完整配置。

## 周期语义

| 周期 | 重置规则 |
|---|---|
| 每日 | 服务器本地时间每天 00:00 |
| 自然月 | 每月 1 日 00:00 |
| 自定义结算周期 | 每月所选结算日 00:00；结算日限制为 1–28 |
| 累计 | 永不自动清零 |

一个用户可以同时配置多类额度。任意额度超限都会触发停用；只有所有会重置的超额原因都消失且累计额度未超限时，账号才会自动恢复。

## 文件与权限

数据位于 `/etc/v2ray-agent/traffic/`：

- `config.json`：额度、阈值和通知设置。
- `state.json`：累计状态、核心计数器基线和周期历史。
- `reports/`：CSV 报告。
- `alerts.log`、`collect.log`：告警和采集日志。

目录权限为 `0700`，其中的配置、状态、报告和日志为 `0600`。Telegram Token 与 Webhook URL 不会输出到菜单或日志。Webhook 仅接受 HTTPS 地址。

## sing-box 限制

sing-box 的每用户统计依赖构建标签 `with_v2ray_api`。v2ray-agent 当前下载的 sing-box 官方发布包没有包含该标签；强行写入 V2Ray API 配置会导致核心无法启动。因此：

- 纯 sing-box 安装会拒绝启用用户流量监控。
- 同时运行 Xray 与 sing-box 时，必须明确确认“仅监控 Xray”；sing-box 协议流量不会计入额度。

此限制是为了避免显示不完整流量或错误停用账号。

## 测试

在仓库根目录运行：

```bash
bash tests/traffic_monitor_test.sh
```

测试覆盖跨协议聚合、计数器去重与归零、四类周期、阈值告警去重、自动停用/恢复、原路由保留、残留锁恢复和 CSV 报告。
